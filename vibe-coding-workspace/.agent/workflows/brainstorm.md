# /brainstorm - Thu thập Yêu cầu

## Khi nào sử dụng
- Bắt đầu dự án mới
- Thêm tính năng mới
- Cần làm rõ requirements

## Quy trình
1. Review context hiện tại
2. Hỏi từng câu hỏi một
3. Tóm tắt Understanding Summary
4. Xác nhận với user
5. Đề xuất 2-3 phương án thiết kế
6. Ghi Decision Log

## Cú pháp
```
/brainstorm [mô tả ý tưởng]
```

## Ví dụ
```
/brainstorm Tôi muốn làm app quản lý công việc cho team

/brainstorm Thêm tính năng đăng nhập bằng Google

/brainstorm Cần giải pháp cho việc sync data offline
```

## Output
- Understanding Summary (5-7 bullets)
- Assumptions list
- Open Questions
- Design options (2-3)
- Decision Log

## Tips
- Answer từng câu hỏi một cách chi tiết
- Confirm understanding trước khi tiếp tục
- Không skip non-functional requirements
