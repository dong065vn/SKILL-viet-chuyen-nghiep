# Workflow: Tạo Mục Lục Tổng Quát

Quy trình linh hoạt để tạo mục lục cho các loại tài liệu học thuật khác.

---

## Sử dụng cho:
- Báo cáo nghiên cứu
- Bài hội thảo khoa học
- Luận văn thạc sĩ
- Các tài liệu học thuật khác

---

## Bước 1: Xác định loại tài liệu

```
@TOC_Architect /brainstorm tạo mục lục
```

**Agent sẽ hỏi:**
- [ ] Đây là loại tài liệu gì?
- [ ] Mục đích của tài liệu?
- [ ] Đối tượng độc giả?
- [ ] Có mẫu/template cần tuân theo không?
- [ ] Yêu cầu đặc biệt?

---

## Bước 2: Thu thập thông tin chi tiết

Tuỳ theo loại tài liệu, agent sẽ hỏi thêm các câu hỏi phù hợp.

---

## Bước 3: Đề xuất cấu trúc

```
@TOC_Architect /outline đề xuất cấu trúc phù hợp
```

---

## Bước 4: Tùy chỉnh và hoàn thiện

```
@TOC_Architect /structure tạo mục lục hoàn chỉnh
```

---

## Bước 5: Trích dẫn (nếu cần)

```
@Academic_Advisor /cite tạo danh mục TLTK
```

---

## Kết quả

Mục lục được lưu tại: `ketqua/mucluc_[loai]_[ten].md`

---

## Shortcut

```
/toc [mô tả loại tài liệu]
```
