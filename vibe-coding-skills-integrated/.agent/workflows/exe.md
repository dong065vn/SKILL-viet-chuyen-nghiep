# /exe - Package .exe

## Cách dùng
```
/exe [app name]
```

## Quy trình
1. Build production
2. Create Inno Setup script
3. Compile installer
4. Sign executable (optional)

## Skill sử dụng
- `deployment-procedures` - Packaging

## Output
- `setup.exe` installer
- Inno Setup script
