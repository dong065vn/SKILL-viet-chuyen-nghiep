# /brain - Brainstorm

## Cách dùng
```
/brain [ý tưởng/vấn đề]
```

## Quy trình
1. Thu thập thông tin từ user
2. Đặt câu hỏi làm rõ
3. Liệt kê features/requirements
4. Đề xuất giải pháp

## Skill sử dụng
- `brainstorming` - Thu thập yêu cầu
- `concise-planning` - Lập kế hoạch

## Output
- Danh sách requirements
- Feature list ưu tiên
