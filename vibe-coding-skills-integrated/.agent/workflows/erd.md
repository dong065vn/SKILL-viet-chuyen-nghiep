# /erd - Thiết kế Database

## Cách dùng
```
/erd [mô tả entities/tables]
```

## Quy trình
1. Phân tích entities và relationships
2. Tạo ERD diagram (Mermaid)
3. Generate Prisma schema
4. Xuất migration script

## Skill sử dụng
- `database-design` - Schema design
- `mermaid-expert` - ERD diagram
- `prisma-expert` - Prisma schema

## Output
- ERD diagram
- `prisma/schema.prisma`
