# /test - Testing

## Cách dùng
```
/test [file/function]
```

## Quy trình
1. Phân tích code cần test
2. Viết unit tests (Jest/Vitest)
3. Run tests
4. Coverage report

## Skill sử dụng
- `javascript-testing-patterns` - Jest/Vitest
- `e2e-testing-patterns` - E2E tests

## Output
- Test files (`*.test.ts`)
- Coverage report
