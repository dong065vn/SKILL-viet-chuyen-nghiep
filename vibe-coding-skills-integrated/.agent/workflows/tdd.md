# /tdd - Test-Driven Development

## Cách dùng
```
/tdd [feature description]
```

## Quy trình
1. Viết failing test
2. Implement minimum code
3. Pass test
4. Refactor

## Skill sử dụng
- `tdd-workflow` - TDD methodology

## Output
- Test file
- Implementation
- Refactored code
