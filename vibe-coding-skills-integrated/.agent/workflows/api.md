# /api - Tạo CRUD API

## Cách dùng
```
/api [model name]
```

## Quy trình
1. Đọc Prisma schema
2. Generate CRUD endpoints
3. Thêm validation (Zod/Yup)
4. Error handling

## Skill sử dụng
- `api-patterns` - REST patterns
- `api-design-principles` - Best practices

## Output
- API routes/controllers
- Request/Response types
