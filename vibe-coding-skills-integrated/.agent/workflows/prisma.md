# /prisma - Prisma Setup

## Cách dùng
```
/prisma [model description]
```

## Quy trình
1. Khởi tạo Prisma (`npx prisma init`)
2. Tạo schema từ mô tả
3. Generate migration
4. Seed data (nếu cần)

## Skill sử dụng
- `prisma-expert` - Prisma patterns

## Output
- `prisma/schema.prisma`
- Migration files
- Prisma client
