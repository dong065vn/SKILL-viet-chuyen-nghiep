# /flow - Tạo Flowchart

## Cách dùng
```
/flow [mô tả ứng dụng]
```

## Quy trình
1. Phân tích mô tả ứng dụng
2. Xác định các bước/quy trình chính
3. Tạo Mermaid flowchart diagram
4. Xuất file `.md` với diagram

## Skill sử dụng
- `mermaid-expert` - Tạo diagram chuẩn
- `brainstorming` - Phân tích yêu cầu

## Output
- Flowchart diagram (Mermaid)
- File `flowchart.md` trong project
