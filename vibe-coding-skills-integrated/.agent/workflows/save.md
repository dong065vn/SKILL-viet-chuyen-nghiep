# /save - Git Save

## Cách dùng
```
/save [commit message]
```

## Quy trình
1. Stage all changes
2. Commit với message
3. Push to remote

## Skill sử dụng
- `git-pushing` - Git workflow
- `commit` - Commit conventions

## Output
- Commit created
- Pushed to remote
