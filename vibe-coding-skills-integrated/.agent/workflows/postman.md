# /postman - Postman Collection

## Cách dùng
```
/postman [api routes]
```

## Quy trình
1. Scan API endpoints
2. Generate Postman collection
3. Thêm test scripts
4. Environment variables

## Skill sử dụng
- `api-patterns` - API structure

## Output
- `postman_collection.json`
- `postman_environment.json`
