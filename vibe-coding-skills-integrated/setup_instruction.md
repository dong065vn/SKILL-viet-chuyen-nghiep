# Vibe Coding Skills Integrated Workspace

## Hướng dẫn sử dụng

### Cài đặt
1. Copy folder này vào project của bạn
2. Mở project trong VS Code/Cursor với AI assistant
3. Sử dụng /commands để kích hoạt workflows

### /Commands theo Module

| Module | Commands |
|--------|----------|
| **1. Planning** | `/flow` `/erd` `/brain` |
| **2. Backend** | `/setup` `/prisma` `/docker` |
| **3. API/Test** | `/api` `/postman` `/test` `/tdd` |
| **4. Auth** | `/auth` `/google` `/clerk` |
| **5. Git** | `/save` `/check` `/gh` |
| **6. UI/UX** | `/ui` `/css` |
| **7. Package** | `/build` `/exe` `/deploy` |

### Quy trình làm việc

```
/brain → /flow → /erd → /prisma → /setup → /api → /auth → /test → /ui → /save → /deploy
```
