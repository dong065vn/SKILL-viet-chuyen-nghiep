# /prd - Viết PRD

## Khi nào sử dụng
- Sau khi brainstorm hoàn thành
- Cần document requirements chính thức
- Trước khi bắt đầu planning

## Quy trình
1. Nhận Understanding Summary từ brainstorm
2. Viết Problem Statement
3. Định nghĩa Solution và Features
4. Tạo User Stories
5. Xác định Success Metrics
6. List Out of Scope
7. RICE prioritization

## Cú pháp
```
/prd [nguồn requirements hoặc context]
```

## Ví dụ
```
/prd viết PRD từ kết quả brainstorm app todo

/prd tạo PRD cho feature đăng nhập Google

/prd update PRD với feedback từ stakeholders
```

## Output
- Complete PRD document với:
  - Overview
  - Problem Statement
  - Solution & Features
  - User Stories
  - Success Metrics
  - Out of Scope
  - Technical Considerations
  - Timeline

## Tips
- Focus Problem trước Solution
- Include measurable success metrics
- Explicitly state Out of Scope
- Use RICE cho feature prioritization
