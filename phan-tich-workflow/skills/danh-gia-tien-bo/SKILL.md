# 📊 Đánh Giá Tiến Bộ — Progress Assessment

## Mục đích

Đánh giá **bạn đang ở đâu** trong hành trình và **cần làm gì tiếp**.

| Yếu tố | Câu hỏi đánh giá | Điểm (1-5) |
|---------|-------------------|-----------|

## 4️⃣ Action Items

Dựa trên đánh giá, gợi ý hành động cụ thể:

### Nếu Tư Duy Đúng yếu (< 3/5):
- [ ] Quay lại skill `tu-duy-dung` — làm lại First Principles Analysis
- [ ] Áp dụng thêm Mental Models
- [ ] Thực hành 5 Whys với mentor

### Nếu Kiến Thức Đúng yếu (< 3/5):
- [ ] Quay lại skill `kien-thuc-dung` — làm Knowledge Gap Analysis
- [ ] Tìm thêm curated resources
- [ ] Dùng AI prompt patterns để học nhanh hơn

### Nếu Công Cụ Đúng yếu (< 3/5):
- [ ] Quay lại skill `cong-cu-dung` — review Tool Selection Matrix
- [ ] Luyện thêm giờ (chưa đủ 20h)
- [ ] Focus vào deliberate practice
