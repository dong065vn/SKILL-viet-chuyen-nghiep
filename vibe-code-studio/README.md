## 🌟 Ba Trụ Cột Vận Hành

### 1. IPO (Input - Process - Output) - Khung Tư Duy Giải Quyết Vấn Đề
Mọi thao tác với hệ thống đều phải tuân thủ chuẩn giao tiếp minh bạch:
- **Input (Dữ liệu vào):** Đầu vào sạch sẽ, chứa ngữ cảnh rõ ràng và thiết lập các ràng buộc trước khi viết mã.
- **Process (Xử lý):** Luồng suy nghĩ (chain-of-thought) có tính định hướng logic chứ không phó mặc.
- **Output (Đầu ra):** Kết quả đạt chuẩn theo định dạng mong muốn, chốt action rõ ràng.

### 2. Vibe Working - Phương Pháp Quản Trị Không Gian Làm Việc
Làm việc dựa trên luồng dữ liệu 1 chiều, tránh lộn xộn:
- `01_Inputs/`: Dữ liệu gốc (READ-ONLY). Không được ghi đè.
- `02_Process/`: Vùng làm việc trung gian, nơi Agent viết nháp và chạy lệnh test.
- `03_Outputs/`: File chuẩn hoặc source code hoàn chỉnh cuối cùng đã được kiểm duyệt.

### 3. KWSR - Mô Hình Tiến Hóa Năng Lực AI
Thay vì để mất mát tri thức sau mỗi phiên làm việc, tổ chức theo 4 cấp bậc:
- **Knowledge:** Hệ thống liên tục tích lũy kinh nghiệm, thói quen lập trình tự động.
- **Workflow:** Các luồng công việc chuẩn hóa (quy trình biên dịch, deploy).
- **Skill:** Kỹ năng xử lý riêng được lưu lại, tự động kích hoạt.
- **Rule:** Định nghĩa phong cách viết mã (Clean Code, DRY) kiên cố như văn bản hiến pháp.

## 🛠 Hướng Dẫn Sử Dụng Nhanh

### Cài Đặt Không Gian Làm Việc
Chỉ cần mở thư mục dự án và gọi lệnh cài đặt bộ Kit:
```bash
npx @vudovn/ag-kit init
```

### Triển khai Vibe Code
Không cần phải nhắc lại các kỹ năng, AI sẽ tự động phân tích:
1. Giao tiếp qua file `task.md` ở `brain/` nếu cần checklist lớn.
2. Dùng Workflow thực chiến: Khi bạn muốn một hệ lệnh chuẩn mực:
```text
/thuc-chien-vibe [Yêu cầu cần xử lý]
```
3. Đóng gói mã thành Skill tái sử dụng với lệnh `/dong-goi-vibe-skill`

## ⚠️ Lưu Ý Quan Trọng khi dùng Editor (Cursor/Windsurf)
Hãy đảm bảo folder `.agent/` KHÔNG bị ignore trong Git nếu bạn muốn Editor AI đọc nội dung workflows làm gợi ý autocomplete. Trừ khi bạn thêm file cấu hình ignore cục bộ: `.git/info/exclude`.
