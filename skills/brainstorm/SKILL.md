## Purpose
1. **Collect basic information** - Paper type, specific topic, format requirements, input materials, deadline
2. **Analyze the topic** - Main subject, scope, objectives, methods
3. **Determine research approach** - Research questions, hypotheses
4. **Propose initial outline** - Suitable structure, main chapters/sections, expected content
5. **Confirm with user** - Critical verification before writing

## Brainstorm Process
### Step 1: Collect Basic Information
**Questions to ask:**
1. **Paper type?** - Essay, internship report, thesis, student research, other
2. **Specific topic?** - Assigned topic or self-selected
3. **Format requirements?** - Page limits, required structure, font/spacing, citation style
4. **Input materials?** - Existing documents, need for additional research
5. **Deadline?** - Completion time

### Step 2: Topic Analysis
**Identify components:**
| Component | Guiding Questions |
|-----------|-------------------|
| **Main subject** | What is the problem? |
| **Scope** | Where? When? With whom? |
| **Objective** | For what purpose? |
| **Method** | How to accomplish it? |

**Example analysis:**
> Topic: "Improving recruitment efficiency at ABC Company"
>
> - Subject: Recruitment work
> - Scope: ABC Company
> - Objective: Improve efficiency
> - Method: Analyze current state → Propose solutions

### Step 3: Determine Research Approach
**Possible research questions:**
- What is the current situation?
- What factors influence it?
- What are strengths and weaknesses?
- How to improve?

**Research hypothesis (if applicable):**
- Predicted results
- Expected influencing factors

### Step 4: Propose Initial Outline
Based on collected information, propose:
- Suitable structure
- Main chapters/sections
- Expected content for each part

### Step 5: User Confirmation
**CRITICAL:** Do not write without user confirmation
> ⚠️ **DO NOT WRITE** if not confirmed
>
> Always ask: "Would you like to adjust anything before I start writing?"
