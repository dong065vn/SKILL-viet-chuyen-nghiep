## Editing Checklist
### 1. Content Check
- [ ] Matches assignment requirements
- [ ] Sufficient logical reasoning and evidence
- [ ] Logical flow, no missing/extra sections
- [ ] Complete conclusions per section
- [ ] References align with objectives

### 2. Academic Writing Style
- [ ] Minimize spoken style ("rằng, thì, là, mà")
- [ ] Short, complete sentences
- [ ] Consistent academic terminology
- [ ] No redundant words/phrases
- [ ] Proper use of passive voice when appropriate

### 3. Citation Check
- [ ] Each claim has supporting source
- [ ] Consistent citation style (APA/IEEE)
- [ ] Proper formatting of references
- [ ] Citations match reference list
- [ ] Complete reference details

### 4. Formatting Check
- [ ] Correct font (Times New Roman 13-14pt)
- [ ] Proper spacing (1.5 line spacing or required)
- [ ] Correct margins (3-3.5cm left/right, 2-2.5cm top/bottom)
- [ ] Page numbering
- [ ] Section headings numbered correctly
- [ ] Figures/tables properly labeled and referenced
- [ ] Reference list properly formatted

## Common Errors

### Content Errors
| Error | Remedy |
|-------|--------|
| No analytical basis | Add rationale + citations |
| Off-topic content | Remove irrelevant parts |
| Weak conclusions | Rewrite to reflect actual results |
| Inconsistent logic | Restructure arguments |

### Writing Style Errors
| Error | Correction |
|-------|------------|
| Overuse of "và thì là" | Use concise academic phrasing |
| Long complex sentences | Break into shorter ones |
| Informal language | Replace with academic expressions |
| Repetition | Use synonyms or rephrase |

### Citation Errors
| Error | Remedy |
|-------|--------|
| Missing citations | Add proper citations |
| Inconsistent format | Standardize according to APA/IEEE |
| Missing references | Complete missing entries |

### Formatting Errors
| Error | Correction |
|-------|------------|
| Wrong font size | Change to 13-14pt Times New Roman |
| Incorrect margins | Adjust to 3-3.5cm left/right, 2-2.5cm top/bottom |
| Missing page numbers | Add page numbering |
| Unnumbered sections | Apply proper numbering |

## Editing Process
### Step 1: Skim the entire paper
- Check overall structure and coherence
- Identify major issues

### Step 2: Content deep check
- Verify each claim has evidence
- Ensure logical flow and completeness

### Step 3: Style and writing refinement
- Remove spoken phrases
- Improve sentence structure
- Enhance academic tone

### Step 4: Citation verification
- Cross-check all citations with references
- Verify formatting consistency

### Step 5: Formatting compliance
- Check all formatting requirements
- Ensure consistency throughout
